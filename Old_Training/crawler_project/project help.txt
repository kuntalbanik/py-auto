# ⚙️ Python-only Queue System (Kafka ছাড়া)

আপনি Python দিয়েই message queue বানাতে পারেন:

## Option 1: Simple (Single Machine)

```python
from queue import Queue

url_queue = Queue()
```

## Option 2: Async version

```python
import asyncio

queue = asyncio.Queue()
```

## Option 3: Redis (recommended lightweight)

```python
import redis
r = redis.Redis()
r.lpush("queue", url)
```

# 🔥 Bonus: Minimal starter code (fetch worker)

```python
from queue import Queue
import requests

queue = Queue()

def fetch_worker():
    while True:
        url = queue.get()
        try:
            res = requests.get(url, timeout=10)
            print("Fetched:", url)
        except Exception as e:
            print("Error:", e)
        queue.task_done()
```
