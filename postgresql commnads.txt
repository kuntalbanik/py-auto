# Connect locally with standard username and database
psql -d <db_name> -U <username>

# Connect to a remote server specifying port and host IP
psql -h <host_ip> -p <port> -d <db_name> -U <username>

# Run a single query directly from the shell without entering the prompt
psql -U <username> -d <db_name> -c "SELECT * FROM users;"

# Execute an entire SQL script file against a database
psql -U <username> -d <db_name> -f /path/to/script.sql

# Backup/Dump a single database into a plain text SQL file
pg_dump -U <username> <db_name> > backup.sql

# Restore a database using a plain text dump file
psql -U <username> <db_name> < backup.sql

# Backup an entire PostgreSQL server cluster (all databases)
pg_dumpall -U <username> > all_databases.sql

🛠️ Exhaustive psql Meta-Commands
Execute these helper shortcuts inside the interactive psql console. Do not append a semicolon to these commands.

Core Utility & Session Management
•	\l or \list: List all databases on the cluster, showing owners and encoding.
•	\c <db_name> or \connect <db_name>: Switch the active session to a different database.
•	\conninfo: Show connection parameters (host, user, port, SSL status).
•	\password <username>: Securely change the password for the specified user role.
•	\q: Terminate your psql shell session and return to the OS terminal.


Structural Inspection (Add + for sizes and descriptions)
•	\d: List all tables, views, and sequences in the public schema.
•	\d <relation_name>: Describe schema details, datatypes, indexes, and constraints for a specific target.
•	\dt: List tables only.
•	\dv: List views only.
•	\dm: List materialized views.
•	\di: List indexes only.
•	\ds: List sequences only.
•	\dn: List defined schemas.
•	\df: List functions and stored procedures.
•	\dx: List all active extensions installed in the current database.
•	\dT: List all existing data types.
•	\db: List tablespaces.


Buffer, Output, & Query Formatting
•	\x: Toggle expanded output mode. It flips row displays to a vertical layout (ideal for wide tables).
•	\timing: Toggle execution timers. It tracks query speeds in milliseconds.
•	\i <file_path>: Read and execute SQL statements directly from an external file.
•	\o <file_path>: Redirect all subsequent query output directly into a specified file instead of displaying it on screen.
•	\e: Open the active query buffer inside an external text editor (like Vim or Nano).
•	\g: Send the current query input buffer to the server backend for immediate execution.
•	\watch <seconds>: Auto-repeat the current query in the buffer continuously at the specified interval.
•	\s <file_path>: Review or save your command-line input history to a file.
•	\! <shell_command>: Execute a native host OS terminal command from within psql (e.g., \! ls -la


Control Flow Blocks (Scripting)
•	\if <expression>: Evaluate a condition to start a conditional scripting block.
•	\elif <expression>: Test an alternate criteria within a conditional chain.
•	\else: Fallback step if previous evaluations fail.
•	\endif: Formally terminate the active conditional logic sequence.
